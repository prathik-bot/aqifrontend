# AQI display app
Next.js, React.js, AQI API (for integration)



# Installation

### Clone the repository to your local machine:
    cd aqifrontend

### Install dependencies
    npm install

### Run the program
    npm dev

# Target Site
    http://localhost:3000/

# Technology Stack
- Built with node version 18.17.0
- Built with next version 9.6.7
